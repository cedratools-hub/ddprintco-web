# D&D Print Co. — Website

Primera versión del sitio corporativo de **D&D Print Co.**

## Concepto
**Fabricación bajo demanda / On-Demand Manufacturing**

No se presenta como una simple imprenta 3D. La propuesta es convertir ideas, piezas, archivos y problemas en soluciones físicas mediante diseño, prototipado y producción bajo demanda.

## Dominio
- Principal: https://ddprintco.com
- Secundario: https://ddprintco.com.mx (redirigir al .com)

## Estructura v1
- Hero
- 4 rutas de entrada: idea / pieza / archivo / problema
- Soluciones
- Materiales
- Proceso
- Reto D&D
- Historia Dude & Dude
- Solicitud de cotización
- SEO base + sitemap + robots
